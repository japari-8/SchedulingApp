# Title: Scheduling App

## Purpose:
GUI based scheduling desktop application that allows users to Add, update, and delete customers and appointments.

## Author:
Juan Aparicio  
Contact: japari6@wgu.edu
V 0.0.1   Date: 12-23-2024

## Tech Stack
IntelliJ Community 2023.2.2  
Java JDK version 17.0.1  
JavaFX-SDK-17.0.6  
mysql-connector-java-8.0.25

## Directions:
Launch Scheduling app, login, message will appear for upcoming appointment.
In Dashboard top section displays customers and buttons to add/delete/update customer data.
Add and delete buttons will redirect to forms. In Dashboard bottom sections displays appointments.
User can filter appointments for the next 30 days or 7 days. Add and delete buttons redirect to forms.
Run Reports button redirects to 3 different type of reports.
Third report filters all appointments by Country.
